# R Data Analysis Buddy

An analytics workspace for cleaning, exploring, and documenting synthetic datasets using R and Markdown best practices.

## Overview

This repository contains R scripts and R Markdown files designed to process data, generate summary statistics, and visualize trends using structured, reproducible code workflows.

## Installation

To run this project locally, clone the repository and install the required R packages:

```bash
# Clone repository
git clone https://github.com/Mhd-barakat/markdown-buddy-Mohamad-Barakat.git

# Required R packages
install.packages(c("tidyverse", "knitr", "rmarkdown"))
```
